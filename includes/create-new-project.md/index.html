The Integration project will contain all the required artifacts for the integration solution. 1. Launch VS Code with the WSO2 Integrator: MI extension installed. 2. Click on the WSO2 Integrator: MI icon on the Activity Bar of the VS Code editor. <a href="https://mi.docs.wso2.com/en/4.6.0/assets/img/develop/mi-for-vscode/mi-vscode-extension.png" class="glightbox"><img src="https://mi.docs.wso2.com/en/latest/assets/img/develop/mi-for-vscode/mi-vscode-extension.png" alt="MI VS Code Extension" width="80%"></a> 3. Click **Create New Project** on **Design View**. <a href="https://mi.docs.wso2.com/en/4.6.0/assets/img/develop/mi-for-vscode/qsg/design-view-pane-create-new-project.png" class="glightbox"><img src="https://mi.docs.wso2.com/en/latest/assets/img/develop/mi-for-vscode/qsg/design-view-pane-create-new-project.png" alt="Design View Pane Create New Project" width="80%"></a> Next, the **Project Creation Form** will be opened.
