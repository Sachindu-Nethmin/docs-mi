# Installation Options WSO2 Integrator: MI provide the following installation options for deployments. 1. [Kubernetes(Helm)](#1-kubernetes-helm) 2. [Docker/Docker Compose](#2-dockerdocker-compose) ## 1. Kubernetes (Helm) You can follow the guides available in the [Helm resources repository](https://github.com/wso2/helm-mi.git) in order to deploy WSO2 Integrator: MI in Kubernetes using Helm artifacts. ## 2. Docker/Docker Compose You can follow the guides available in the [Docker Resources repository](https://github.com/wso2/docker-ei/tree/4.2.x) in order to deploy WSO2 Integrator: MI using Docker artifacts.
