# Proxying a REST Service Sample This sample includes a service that acts as a proxy for an existing RESTful service. When a client invokes this service, it forwards the message to the backend service without altering its content. Specifically, the sample features a REST API called UserInfoRestAPI, which serves as the proxy. Additionally, it includes an HTTP endpoint named UsersHttpEP that represents the actual backend service within the MI context. ## Deploying the sample 1. Open the sample by clicking on the **Proxying a REST Service** card. 2. Give a folder location to save the sample. 3. [Build and run]({{base_path}}/develop/deploy-artifacts#build-and-run) the sample in your WSO2 Integrator: MI. ## Running the sample 1.
