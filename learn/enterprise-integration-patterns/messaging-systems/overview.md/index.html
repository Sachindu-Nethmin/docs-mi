# Messaging Systems Messaging is one integration style out of many, used for connecting various applications in a loosely coupled, asynchronous manner. Messaging decouples the applications from data transferring, so that applications can concentrate on data and related logic while the messaging system handles the transferring of data. This chapter introduces the basic patterns used when implementing enterprise integration using messaging and how they are simulated using the WSO2 Integrator: MI.
