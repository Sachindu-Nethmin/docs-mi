# Messaging Channels A Message channel is a basic architectural pattern of a [messaging system]({{base_path}}/learn/enterprise-integration-patterns/messaging-systems/overview) and is used fundamentally for exchanging data between applications. An application can use a channel to make a specific type of data available to any receiver applications that need to consume that type of data.
