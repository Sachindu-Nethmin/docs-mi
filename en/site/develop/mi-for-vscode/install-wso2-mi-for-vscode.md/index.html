--- tags: - vscode - extension --- # Install WSO2 Integrator: MI for VS Code This page explains how to install the WSO2 Integrator: MI for VS Code extension. ## Prerequisites - Visual Studio Code Download and install the Visual Studio Code editor from <a target="_blank" href="https://code.visualstudio.com/download">here</a>. ## Install the MI for VS Code extension Follow one of the following two options to install MI for VS Code: **Option 1** 1. Go to the <a target="_blank" href="https://marketplace.visualstudio.com/items?itemName=WSO2.micro-integrator">Visual Studio Code Marketplace</a>. 2. Click **Install** to install the **WSO2 Integrator: MI** extension. **Option 2** 1. Open the VS Code editor. 2. Click the **Extensions** icon in the Activity Bar of the VS Code. <a href="{{base_path}}/assets/img/develop/mi-for-vscode/extensions.png" class="glightbox"><img src="{{base_path}}/assets/img/develop/mi-for-vscode/extensions.png" alt="Extensions" width="80%"></a> 3. Type `WSO2 Integrator: MI` in the search bar. 4. Press **Enter** to search. 5. Among the results, find the **WSO2 Integrator: MI** extension. <a href="{{base_path}}/assets/img/develop/mi-for-vscode/extension-search-list.png" class="glightbox"><img src="{{base_path}}/assets/img/develop/mi-for-vscode/extension-search-list.png" alt="Extensions" width="30%"></a> 6. Click **Install** to install the MI for VS Code extension from Visual Studio Marketplace. When the extension is activated correctly, the WSO2 Integrator: MI icon appears on the Activity Bar of the VS Code editor. <a href="{{base_path}}/assets/img/develop/mi-for-vscode/mi-vscode-extension.png" class="glightbox"><img src="{{base_path}}/assets/img/develop/mi-for-vscode/mi-vscode-extension.png" alt="MI VS Code Extension" width="80%"></a>
