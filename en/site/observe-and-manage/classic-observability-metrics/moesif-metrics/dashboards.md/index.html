# Moesif Dashboards for WSO2 Integrator: MI ## Import MI dashboards to Moesif 1. Download the <a href="{{base_path}}/assets/attachments/moesif-metrics/dashboards_template.json" download="dashboards_template.json">dashboards_template.json</a> file containing the template dashboards for MI. 2. On the Moesif UI, click on **Create New** → **Dashboard Templates** → **Import JSON Template** and provide the JSON template downloaded above. <a href="{{base_path}}/assets/attachments/moesif-metrics/dashboard_templates.png" class="glightbox"><img src="{{base_path}}/assets/attachments/moesif-metrics/dashboard_templates.png" width="70%" alt="Moesif Dashboard Templates"></a> The new dashboards will be visible under your Saved Dashboards along with the default Moesif Dashboards. ## Dashboards ### Overall dashboard This dashboard
