# Salesforce Marketing Cloud Connector Reference The following operations allow you to work with the Salesforce Marketing Cloud connector. Click an operation name to see parameter details and samples on how to use it. ## Initialize the connector To use the Salesforce Marketing Cloud connector, first create the connection with your configuration.
