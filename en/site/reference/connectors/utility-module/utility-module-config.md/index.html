# Utility Module Reference The Utility Module in WSO2 Enterprise Integrator helps to perform basic utility functions such as math, string, date, and signature. The connector will compute the result and save it to a property. The string can contain any characters. It will also consider whitespace characters when calculating the length.</td> </tr> <tr> <td>Target Property</td> <td>target</td> <td><code>length</code></td> <td>Specify the property name to which the result should be saved.</td> </tr> </tbody> </table> ### Sample configuration The following is a sample request, Synapse configuration, and response for the given request. === "Request" ``` {"string":"utility module"} ``` === "Synapse Configuration" ```xml <utility.string.Length> <inpuString>{json-eval($.string)}</inputString> <target>length</target> </utility.string.Length> ``` === "Request" ``` length=14 ``` ##
