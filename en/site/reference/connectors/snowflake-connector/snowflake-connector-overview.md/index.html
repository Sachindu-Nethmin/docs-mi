# Snowflake Connector Overview The Snowflake Connector enables you to utilize a complete range of Snowflake operations using WSO2 MI. It provides functionalities to execute a set of standard Snowflake DDL, DML, and query commands. Go to the <a target="_blank" href="https://store.wso2.com/connector/esb-connector-snowflake">WSO2 Connector Store</a> to download the Snowflake connector. <img src="{{base_path}}/assets/img/integrate/connectors/snowflake-connector.png" title="Jira Connector Store" width="200" alt="Snowflake Connector Store"/> ## Compatibility | Connector version | Supported product versions | |--------------------------------------------------------------------------------|----------------------------| | [1.0.0](https://github.com/wso2-extensions/esb-connector-snowflake/tree/1.0.0) | MI 4.2.0 | ## Snowflake Connector documentation * **[Snowflake Connector Example]({{base_path}}/reference/connectors/snowflake-connector/snowflake-connector-example/)**: This example explains how to use Snowflake Connector to perform DDL, DML and query commands. * **[Snowflake Connector Reference]({{base_path}}/reference/connectors/snowflake-connector/snowflake-connector-reference/)**: This documentation provides a reference guide for the Snowflake Connector. ## How to contribute As an open source project, WSO2 extensions welcome contributions from the community.
