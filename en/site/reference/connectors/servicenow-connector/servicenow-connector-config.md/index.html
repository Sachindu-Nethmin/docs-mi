--- search: boost: 2 --- # ServiceNow Connector Reference ## Connection configuration The connection is used to establish a connection to the ServiceNow instance. The ServiceNow API requires all requests to be authenticated as a user. User has to create a own instance with his user credentials. When you create an account in ServiceNow Developer page then you are enable to create your own instance. For more information, see [the ServiceNow Developer page](https://developer.servicenow.com/app.do#!/home). ??? note "SERVICENOW Connection" <table> <tr> <th>Parameter Name</th> <th>Description</th> <th>Required</th> </tr> <tr> <td>serviceNowInstanceURL</td> <td>The base endpoint URL of the ServiceNow API. </td> <td>Yes.</td> </tr> <tr> <td>username</td> <td>The user Name of the own instance.</td> <td>Yes.</td> </tr> <tr> <td>password</td> <td>The Password of the own instance.</td> <td>Yes.</td> </tr> </table> **Sample configurations** ```xml <servicenow.init> <serviceNowInstanceURL>{$ctx:serviceNowInstanceURL}</serviceNowInstanceURL> <username>{$ctx:username}</username> <password>{$ctx:password}</password> </servicenow.init> ``` **Sample request** ```json { "serviceNowInstanceURL":"https://dev17686.service-now.com", "username":"admin", "password":"12345" } ``` The following operations allow you to work with the ServiceNow Connector.
