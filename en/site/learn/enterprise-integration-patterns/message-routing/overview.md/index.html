# Message Routing A [message router]({{base_path}}/learn/enterprise-integration-patterns/messaging-systems/message-router) is a basic architectural pattern of a messaging system used fundamentally for connecting different message channels. A router consumes a message from one message channel and republishes it to a different channel based on specified conditions.
