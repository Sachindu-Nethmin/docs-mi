# Axis2 Properties !!! Info The following are Axis2 properties that can be used with the [Property mediator]({{base_path}}/reference/mediators/property-mediator) and the [Property Group mediator]({{base_path}}/reference/mediators/property-group-mediator). Axis2 properties allow you to configure the web services engine in WSO2 Integrator: MI, such as specifying how to cache JMS objects, setting the minimum and maximum threads for consuming messages, and forcing outgoing HTTP/S messages to use HTTP 1.0.
