To add service-level transport parameters to a proxy service: 1. Open your proxy service artifact in **MI VS Code extension**. 2. In the **Design View**, click on the **Edit** button and expand the **Advanced Options** section and navigate to **Service Parameters**. <img src="../../../../assets/img/integrate/create_artifacts/new_proxy_service/service-level-params.png" width="700"> 2. Click the `Add Parameter` text button to open the following form to add the parameter name and value as a key-value pair: <img src="../../../../assets/img/integrate/create_artifacts/new_proxy_service/service-level-params-dialog.png" width="700">
