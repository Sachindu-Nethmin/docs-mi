The value provided must be the exact match for an report; otherwise, a bad request (400) error will be returned. * pageSize (Optional - integer): The number of records returned per page in the paginated response * reportParameters (Optional - object): A list of key value pairs for those reports which take as input user supplied parameter values. **Sample request** Following is a sample
