# Microsoft Azure Data Lake Storage Connector Overview The Microsoft Azure Data Lake Storage Connector allows you to access the [Azure Data Lake Storage Gen2 services](https://learn.microsoft.com/en-us/azure/storage/blobs/data-lake-storage-introduction) using Microsoft Azure Storage Java SDK from an integration sequence. Azure Data Lake Storage Gen2 is a cloud-based data storage solution that combines the capabilities of Azure Blob Storage with a hierarchical namespace, optimizing it for big data analytics and scalable data management. It provides high availability, security, durability, and redundancy, making it an ideal choice for enterprises handling large-scale data workloads.
